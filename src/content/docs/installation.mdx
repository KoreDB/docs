KoreDB is an embedded graph database that can be used from the command line and from
a variety of programming languages. This page shows all the ways you can install KoreDB.
After installation, you can learn how to run KoreDB by [creating your first graph](/get-started).

All source code and pre-compiled binaries of KoreDB are distributed under the [MIT License](https://github.com/KoreDB/koredb/blob/master/LICENSE). By installing and using KoreDB, you acknowledge and agree to these terms.

## Command Line (Shell)

If you don't need KoreDB embedded in your application, you can use the CLI shell. This is a standalone
executable with no dependencies that can be used to interact with a KoreDB database using just Cypher.

<Tabs syncKey="cli">
<TabItem label="Linux">

Use a tool like `curl` to download the latest version of the KoreDB CLI to your local machine.
<Code code={DOWNLOAD_LINKS.cli.linux} lang="bash" frame="terminal"/>

Now you can run KoreDB from the command line.

```bash
./koredb
```

</TabItem>

<TabItem label="macOS">

You can install the KoreDB CLI using Homebrew.

```bash
brew install koredb
```

You can now run KoreDB from the command line.

```bash
koredb
```

Alternatively, you can download the KoreDB CLI directly.

<Code code={DOWNLOAD_LINKS.cli.macos} lang="bash" frame="terminal"/>

</TabItem>

<TabItem label="Windows">

Use a tool like `curl` to download the latest version of the KoreDB CLI to your local machine. Alternatively,
simply open 
<a href={DOWNLOAD_LINKS.cli.winUrl} target="_blank">this URL</a> in your browser.

<Code code={DOWNLOAD_LINKS.cli.win} lang="bash" frame="terminal"/>

Right-click on the `koredb_cli-xxx.zip` file and click on **Extract All**. This will create a directory
containing a file named `koredb.exe`. Then, right-click on the directory and click "Open in terminal".
From within the terminal, you can then run `./koredb.exe`.

</TabItem>

<TabItem label="Nix">

On Linux, macOS, and WSL2, you can also use [`Nix`](https://nixos.org/learn) to run the KoreDB CLI.

Run KoreDB in a temporary shell:

```bash
nix-shell -p koredb
koredb
```

Alternatively, you can install KoreDB declaratively using [NixOS](https://nixos.org/manual/nixos/stable/#sec-package-management) or [Home Manager](https://github.com/nix-community/home-manager) configuration:

```nix
{
  environment.systemPackages = [ pkgs.koredb ]; // NixOS
  home.packages = [ pkgs.koredb ];              // Home Manager
}
```

</TabItem>

## Python

You can use `uv`, `pip`, or `nix` to install the KoreDB Python client library.
The instructions are the same for Linux, macOS, and Windows.

## Rust

Use Cargo to install the KoreDB Rust client library. This will by default build and statically link KoreDB's C++
library from source. You can also link against the dynamic release libraries, as described in the [crate docs](https://docs.rs/koredb/latest/koredb/#building).

```bash
cargo add koredb
```

## Swift

To add `koredb-swift` to your Swift project, you can use the Swift package manager.
1. Add the package to your Package.swift dependencies.
    <Code code={DOWNLOAD_LINKS.swift} lang="swift" frame="terminal"/>

    You can change the branch to a tag to use a specific version (e.g., {version} for the latest stable release or `main` for the latest development version).

2. Add `KoreDB` to your target dependencies.
    ```swift
    targets: [
      .target(
        name: "YourTargetName",
        dependencies: [
          .product(name: "KoreDB", package: "koredb-swift"),
        ]
      )
    ]
    ```

Alternatively, you can add the package through Xcode:
1. Open your Xcode project.
2. Go to `File` > `Add Packages Dependencies...`.
3. Enter the URL of the koredb-swift repository: `https://github.com/KoreDB/koredb-swift`.
4. Select the version you want to use (e.g., {version} for the latest stable release or `main` for the latest development version).

Once you've downloaded and extracted the C++ files into a directory, you can link it to your C++
program by adding the directory to your build system's search paths.

## KoreDB Explorer

KoreDB Explorer is a web-based GUI for KoreDB. It allows you to explore and query your KoreDB database
using a web browser. Refer to the KoreDB Explorer [GitHub repo](https://github.com/KoreDB/explorer)
for more details.

## KoreDB MCP Server

Our [Model Context Protocol](https://modelcontextprotocol.io/introduction) server allows you to expose
your KoreDB database as a tool that can be used by LLMs and agents.
Refer to the KoreDB-MCP [GitHub repo](https://github.com/KoreDB/koredb-mcp-server) for more details.

## Nightly Builds

If you want access to the latest features in development, you can use our nightly builds.

- Python: `uv pip install --pre koredb`
- Node.js: `npm i koredb@next`
- Java: The latest snapshot version is available on [GitHub Packages](https://github.com/KoreDB/koredb/packages/2258307)
- For the CLI, C/C++ shared libraries, and Rust crate, the latest nightly versions for each can be
downloaded from the latest run of [this GitHub Actions workflow](https://github.com/KoreDB/koredb/actions/workflows/build-and-deploy.yml).
