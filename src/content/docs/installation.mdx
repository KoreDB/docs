## Release

Use the [KoreDB 0.11.3 Release](https://github.com/KoreDB/koredb/releases/tag/0.11.3)
for release downloads and source code. The release tag is `0.11.3`, without a `v` prefix.
Choose assets for your operating system, architecture, and runtime from its **Assets** list.

The release currently contains Node.js packages and native addons. Build CLI binaries and C/C++
libraries from the `0.11.3` source tag using the instructions below.

:::note[Storage format compatibility]
**KoreDB will always maintain compatibility with the Kuzu 0.11.x storage format.**
This commitment applies to all future KoreDB releases.
:::

KoreDB is derived from [Kuzu](https://github.com/kuzudb/kuzu), initially developed by
K?zu Inc. The engine is distributed under the
[MIT License](https://github.com/KoreDB/koredb/blob/0.11.3/LICENSE).

## Node.js

Install the scoped npm package:

```bash
npm install @koredb/koredb
```

To select the version corresponding to the release:

```bash
npm install @koredb/koredb@0.11.3
```

Use the same package name in your code:

```js
const koredb = require("@koredb/koredb");
```

```js
import { Database, Connection } from "@koredb/koredb";
```

The main package selects the native addon for your platform through optional dependencies.
The [0.11.3 Release](https://github.com/KoreDB/koredb/releases/tag/0.11.3) also provides
`koredb-koredb-0.11.3.tgz` and platform addon tarballs. For an offline installation,
download the main tarball and the matching platform tarball, then pass both local files
to `npm install`.

## Python

Install the [KoreDB package from PyPI](https://pypi.org/project/koredb/) with CPython 3.12 or later.

```bash
pip install koredb
```

Verify the installation:

```bash
python -c "import koredb; print(koredb.__version__)"
```

## Command Line (Shell)

Download a CLI binary for your platform from the
[0.11.3 Release](https://github.com/KoreDB/koredb/releases/tag/0.11.3) when one is available.
If no CLI asset is attached, build the same release from source after installing the
[build prerequisites](/developer-guide):

```bash
git clone --branch 0.11.3 --depth 1 https://github.com/KoreDB/koredb.git
cd koredb
make release
```

The executable is generated in `build/release/tools/shell/` (`koredb` on Linux/macOS,
`koredb.exe` on Windows). Run it to open an in-memory database, or pass a database path.
See [Create your first graph](/get-started) for examples.

## C/C++

Use the [0.11.3 Release](https://github.com/KoreDB/koredb/releases/tag/0.11.3)
for C/C++ libraries and headers when those assets are available. Otherwise, build and
install the libraries from the release source:

```bash
git clone --branch 0.11.3 --depth 1 https://github.com/KoreDB/koredb.git
cd koredb
cmake -S . -B build/release -DCMAKE_BUILD_TYPE=Release
cmake --build build/release --config Release
cmake --install build/release --config Release --prefix ./install
```

Link your application against the installed library and headers.
See the [C API guide](/client-apis/c) and [C++ API guide](/client-apis/cpp).

## Java

Use a Java package from the [0.11.3 Release](https://github.com/KoreDB/koredb/releases/tag/0.11.3)
when available. If no JAR is attached, build the Java binding from the same source tag
with `make java`, following the [developer guide](/developer-guide).
Use the resulting JAR as a local dependency in your application; see
[Create your first graph](/get-started) for a Gradle example.

## Rust

Build the Rust client from the source corresponding to the
[0.11.3 Release](https://github.com/KoreDB/koredb/releases/tag/0.11.3):

```bash
cargo add koredb --git https://github.com/KoreDB/koredb --tag 0.11.3
```

This compiles the C++ library from source and requires the
[build prerequisites](/developer-guide). See the [Rust API guide](/client-apis/rust).

## Go

The [Go API](/client-apis/go) wraps KoreDB's C API. Use C libraries from the
[0.11.3 Release](https://github.com/KoreDB/koredb/releases/tag/0.11.3), or build them from
that source tag as described in [C/C++](#cc). The Go wrapper is maintained separately;
follow its API guide for integration instructions.

## Swift

The [Swift API](/client-apis/swift) is maintained separately. Use the
[0.11.3 Release](https://github.com/KoreDB/koredb/releases/tag/0.11.3) as the engine version
reference and follow the Swift API guide for wrapper integration.
